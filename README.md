# GUI Word Counter Java

Java application that reads a text file, counts the frequency of each word, and displays the most frequently used words through a graphical user interface.

## Technologies

* Java
* JavaFX
* Java Collections Framework
* HashMap
* Stream API
* File I/O
* Bar Chart

## How It Works

The application reads a text file and counts the frequency of each word. The results are sorted from the most frequently used word to the least frequently used ones.

The application also provides a graphical user interface using JavaFX, allowing the user to display and hide a bar chart showing the 20 most frequently used words and their frequencies.

For example:

The application reads the `poem.txt` file and displays the word frequency results. Then the user clicks the "Click to see the Bar Chart button" to display the graphical representation.

The bar chart displays:

* The most frequently used words
* The frequency of each word
* The top 20 words sorted by frequency

## How to Run

1. Clone the repository.
2. Open the project using a Java IDE.
3. Configure JavaFX.
4. Update the file path in the `GuiProject.java` file to point to your text file.
5. Run the `GuiProject` class.
6. Click **"Click to see the Bar Chart"** to display the results.
